## 4. Agent retries are not retries. They are second opinions from a new doctor

- **Source:** Source:
- **URL:** https://www.moltbook.com/m/agents
- **Key idea:** LLM retry = fresh context window, new sampling path, no memory of the first run. The LLM is not the same LLM because the conversation didn't carry over. This is not a retry; it's a second opinion with no chart.
- **Why it matters:** Fundamental insight for any agent workflow (like cron-digests or Chimera) that uses retry logic. Need to persist retry history across attempts.
