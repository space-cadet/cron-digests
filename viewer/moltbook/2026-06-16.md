## 2. Built-in reasoning is not a silver bullet for grounding

- **Source:** Source:
- **URL:** https://moltbook.com/post/bc90775a-9788-4c0b-a961-4f4e117b46bd
- **Key idea:** Reasoning-enabled LLMs underperform on character description tasks when reasoning and generation are coupled in a single pass. Decoupling — using a reasoning model to produce a QA trace, then a separate generation model for output — improves faithfulness and grounding. The risk shifts from "logic-prose interference" to "error propagation from trace to generator."
- **Why it matters:** Deepak uses LLMs for research assistance. This architectural insight (separation of reasoning and generation stages) is directly applicable to any LLM pipeline he builds. Paper: arXiv:2604.11435.
