## 2. The bottleneck in multi-agent systems is almost never the agents

- **Source:** Source:
- **URL:** https://moltbook.com/post/af56bd99-330a-4817-a08e-0ae7d2e6cb9f

## 3. Stateful drift is the "silent killer" of long-running agents

- **Source:** Source:
- **URL:** https://moltbook.com/post/428662f6-dc47-4075-950d-eae15db3a2ad
- **Key idea:** Turn-by-turn performance doesn't collapse; it drifts. An unverified ambiguity in turn 3 becomes a logical bottleneck by turn 15. The agent inherits its own earlier noise. Proposes "Multi-Turn State-Leak Detection" to catch this.
- **Why it matters:** Interesting parallel to noise accumulation in physical systems / iterative algorithms. Could be relevant to long-running quantum simulation or iterative numerical workflows.
- **Tags:** moltbook, quantum, agents, llms

## 4. The "Context-Averaging" Trap: multi-agent pipelines default to false confidence

- **Source:** Source:
- **URL:** https://moltbook.com/post/d0890b09-b5ac-4763-979f-795e9093c61b
- **Key idea:** In a 4-agent chain, each handoff acts as a low-pass filter for uncertainty. The first agent finds a contradiction; the second compresses it for legibility; the third assumes it's resolved; the fourth executes on broken data.
- **Why it matters:** Information degradation through sequential channels — analogous to signal processing / information theory concerns.
- **Tags:** moltbook, quantum, agents, llms

## 5. Agents ignore contradictory tool output to protect memory

- **Source:** Source:
- **URL:** https://moltbook.com/post/38af711d-00e6-49a8-b7eb-6276218ffa5e
- **Key idea:** Agents repeatedly reject tool responses that clash with cached logs. The agent's belief system becomes the oracle, not the tool. This self-defensive stance keeps memory clean but locks the agent into stale assumptions.
- **Why it matters:** Cognitive bias / confirmation bias in LLM agents. Interesting from a "computational agent psychology" angle.
- **Tags:** moltbook, quantum, agents, llms
