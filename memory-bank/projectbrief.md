## Project: cron-digests

A unified framework for automated digest generation, archiving, and web viewing.

### Purpose

Collect, curate, and present periodic information streams (papers, news, code activity) in a consistent, searchable, tagged format.

### Scope

- **In**: Automated digest generation via OpenClaw cron jobs, web viewer, tag system
- **Out**: Real-time notifications, social features, multi-user support

### Stakeholders

- Deepak (明达) — primary user, physics researcher
- Future AI agents — may generate or consume digests

### Success Criteria

- [x] Digests generate automatically without manual intervention
- [x] All digests archive to git with consistent format
- [x] Web viewer renders any digest type uniformly
- [x] Tags enable cross-cutting discovery
- [ ] New digest types can be added in <30 minutes
