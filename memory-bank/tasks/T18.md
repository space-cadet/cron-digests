## Description
Build a verification pipeline that runs after every digest generation to catch silent failures before they reach the viewer. The pipeline must validate digest structure, index correctness, and viewer visibility.

## Root Cause
Multiple incidents where digests existed on disk but were invisible to the viewer:
- `web-science/2026-06-22.md` used regular hyphen `-` instead of em-dash `—` in header, causing `build-index.js` regex to silently skip it
- Subagent in cron job tried to edit `build-index.js` instead of running it, causing "Edit: build-index.js failed" error
- No automated check compared `find *.md` count against `index.json` entries

## What Was Built

### 1. `scripts/verify-digest.sh` — Per-Digest Validation (8 checkpoints)
- Header format check (`## N. Title`)
- Items found vs actual entry count
- Entry structure (title, summary, metadata)
- Index build test (runs `build-index.js` on single file)
- JSON output validation
- SQLite DB validation
- Manifest file existence
- Viewer visibility (file in `viewer/` or indexed)

### 2. `scripts/digest-health-check.sh` — Pipeline Health Check (150 lines)
- **Date gap detection**: Respects each cron schedule (arXiv Tue-Sat, web-science Mon-Fri, moltbook daily)
- **index.json sync**: Compares `find $TYPE/*.md | wc -l` against `index.json` entries per type
- **index.db validity**: SQLite query confirms data exists
- **Latest digest structure**: Header, items, entries validation
- **Manifest check**: All manifest files exist and are valid JSON
- **Playwright tests**: Runs `viewer/test.js` if Playwright available
- **Git status**: Warns if uncommitted changes exist
- **GitHub Pages check**: Confirms latest commit is deployed

### 3. `viewer/test.js` — Enhanced Playwright Tests (10 tests)
1. Page loads and cards render
2. Latest digest is visible as a card
3. Search filters digests correctly
4. Filter buttons (arXiv, web-science, moltbook, all) work
5. Clicking card opens modal with actual content loaded
6. Modal shows digest structure (TOC + paper items)
7. Modal close button works
8. Responsive layout on mobile (375px)
9. Tag chips render in cards
10. Category badges render correctly
11. Latest digest modal has correct title matching date

### 4. Regex Robustness Fix
- `build-index.js` and `validate-digest.js` now accept both `-` and `—` in headers:
  ```js
  const match = header.match(/^#\s+(.+?)\s+[-–—]\s+(\d{4}-\d{2}-\d{2})/);
  ```
- Prevents silent parsing failures from formatting inconsistencies

### 5. Cron Job Architecture Fix
- **Subagent**: Only rewrites paper summaries (safe edit operations on markdown)
- **Main cron job**: Explicitly runs `node scripts/build-index.js` and `git push` via `exec`
- Prevents subagent from attempting to edit script files (which it cannot do)

## Lessons Learned
- Silent parsing failures are the worst kind — file exists but pipeline ignores it
- Always validate pipeline output against source of truth, not just check if files exist
- Subagents should never edit script files — separate content generation from build orchestration
- Regular hyphen vs em-dash is a real bug category in markdown parsers
