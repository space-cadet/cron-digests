## Methods Used

### arXiv Backfill
- Created `scripts/backfill-arxiv.py` — reusable script for future backfills
- Uses arXiv API `submittedDate` range query: `submittedDate:[YYYYMMDD000000 TO YYYYMMDD000000]`
- Queries physics categories: hep-th, gr-qc, quant-ph, cond-mat
- Scores papers by keyword relevance (quantum gravity, loop quantum, black hole, etc.)
- Selects top 15 papers, generates standard digest format
- **Note:** Results may differ slightly from original RSS-based digests since API queries by submission date, not "front page" date

### Web Science Backfill
- Used Phys.org daily top pages: `https://phys.org/visualstories/YYYY-MM-DD-daily-top.amp`
- Manually extracted top 5 stories per date
- Generated standard Web Science digest format

### Moltbook Backfill
- Moltbook API still returning 401 (unauthorized) — same issue as T22
- Created placeholder stubs with "No items found — cron failure" note
- Will be regenerated once T22 (API fix) is resolved

## Lessons Learned

- arXiv API supports historical date-range queries via `submittedDate` — useful for backfills
- Phys.org daily top pages use `/visualstories/YYYY-MM-DD-daily-top.amp` format
- Historical Moltbook placeholder/backfill assumptions were superseded by T22's structured API repair. The old stubs remain historical records; current generation must use validated Moltbook posts or an explicit zero-item result.
