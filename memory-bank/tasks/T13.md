## Pipeline
```
moltbook-research cron job
    → saves to ~/.openclaw/logs/moltbook-research.md
    → runs generate-moltbook-digest.js
        → creates moltbook/YYYY-MM-DD.md
        → updates moltbook/manifest.json
    → push triggers CI
        → build-index.js indexes moltbook digests
        → deploys to GitHub Pages
    → viewer loads index.json
        → renders moltbook entries with amber badge
        → shows submolt name as chip
        → shows author/relevance as meta line
        → links to original Moltbook URL
```

## Architecture Update — 2026-08-26

The original freeform-log parser has been retired. Moltbook research now uses the shared `scripts/moltbook-client.mjs` used by the personal Moltbook job. It queries the validated `/submolts/{name}/feed` endpoint, filters exact submolt matches, validates `moltbook.com` URLs, deduplicates posts, and writes structured private raw data before generating the public digest. A zero-result run produces an explicit zero-item digest and never recycles historical research.
