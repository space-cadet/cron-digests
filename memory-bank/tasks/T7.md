## Completion Criteria
- [x] CSS variables for light/dark themes with toggle button and localStorage persistence
- [x] Tag filter bar: top-20 tags with counts, clickable to filter digests by tag
- [x] Per-card tag chips (up to 6), clickable to activate filter
- [x] "New" badge on latest digest card (most recent date)
- [x] PDF links in modal for arXiv entries alongside abstract links
- [x] Keyboard navigation: `j`/`k` arrows, `Enter` to open, `/` to focus search, `Esc` to close/blur
- [x] Mouse hover syncs keyboard focus index for seamless transition
- [x] Compact tag chips (smaller padding, font, border-radius)
- [x] arxivite.org replaces arxiv.org for all paper links (abstract + PDF)
- [x] Viewer loads `index.json` instantly instead of N markdown fetches
