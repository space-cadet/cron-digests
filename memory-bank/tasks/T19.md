## Description
User reported 404 when accessing cron-digest viewer. Diagnosed and fixed URL confusion.

## Root Cause
User was accessing: `https://space-cadet.github.io/cron-digests/viewer/index.html`
Correct URL: `https://space-cadet.github.io/cron-digests/`

The GitHub Actions CI workflow (`.github/workflows/ci.yml`) deploys the `viewer/` directory as the **root** of the GitHub Pages site. The `viewer/` prefix is not part of the deployed URL.

## How CI Deployment Works
1. `validate-and-index` job copies `arxiv/`, `web-science/`, `moltbook/` into `viewer/`
2. `build-index.js` generates `viewer/index.json` and `viewer/index.db`
3. `deploy` job uploads `viewer/` directory as artifact
4. `actions/deploy-pages@v4` deploys artifact root to Pages

So `viewer/index.html` becomes `/index.html` at `space-cadet.github.io/cron-digests/`
