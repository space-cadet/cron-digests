## Context
- **Headless vs Headed:** On VPS, headless mode leaks detection signals (bot.sannysoft.com flags "Headless" and "webdriver"). Headed mode with `xvfb-run --auto-servernum --server-args='-screen 0 1280x720x24'` passes all checks.
- **Fingerprint:** CloakBrowser presents realistic Windows + NVIDIA GeForce RTX 4060 profile, 5 plugins, proper WebGL vendor/renderer.
- **reCAPTCHA test:** Widget loads and checkbox is interactable.
- **Phys.org test:** 66 articles loaded and extracted successfully.
- **ESM-only:** CloakBrowser uses `import` syntax, not `require`. Script is `.mjs` extension.
- **Path portability:** Script uses `__dirname` from `fileURLToPath(import.meta.url)` instead of hardcoded home directory paths.
