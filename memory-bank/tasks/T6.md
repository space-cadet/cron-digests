## Context
- **Schema drift identified:** `TEMPLATE.md` specified `**Source:**` but actual digests use `**Authors:**`, `**arXiv ID:**`, etc. Schema captures the actual de-facto v2.0 format.
- **Validator is structural only:** `###` headers inside entries are treated as body content, not violations. This allows old footers to exist without breaking the item counter.
- **SQLite approach chosen over live DB:** GitHub Pages is static hosting; pre-computed JSON index enables fast client-side queries without backend complexity.
- **User granted sqlite3 install permission** for the indexing layer.
