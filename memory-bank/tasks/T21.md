## What Was Done

### Calendar View
- Month grid with navigation (prev/next month)
- Colored dots per source: 🔵 arXiv, 🟣 Web Science, 🟠 Moltbook
- Today highlight with "TODAY" label
- Shorter cells (70px min-height), bigger dots (10px)
- Legend at bottom

### Day Modal (Calendar Click)
- Shows all digests for selected day
- Digest cards with colored left borders by type
- Individual paper titles (not comma-separated)
- "Click to read full digest →" link
- Clicking card opens the full digest modal

### Browser History Navigation
- URL hash updates: `#day=2026-07-02` → `#digest=2026-07-02-arxiv`
- Back button: digest modal → day modal → close
- Forward button: reopens modals in sequence
- `popstate` listener handles all transitions

### List View Improvements
- Month-grouped sticky headers (July 2026, June 2026, May 2026)
- Cards grouped under each month header
- Sticky positioning with accent border

### Cache Busting
- Cloudflare caches JS aggressively (6-month max-age)
- Query params (`?v=3`) don't bust Cloudflare cache
- Solution: versioned filenames (`app.v3.js`, `search.v3.js`, etc.)
