### T13: Moltbook Research Stream Integration
Integrated the Moltbook research stream into the cron-digests viewer as a third source alongside arXiv and Web Science.

**Full pipeline implemented:**
1. **Cron job** `moltbook-research` runs every 6h at :30, saves findings to `~/.openclaw/logs/moltbook-research.md`
2. **Generator script** `scripts/generate-moltbook-digest.js` parses the log into a dated digest file + updates manifest
3. **Index builder** `scripts/build-index.js` indexes moltbook digests into SQLite + JSON
4. **Viewer** `viewer/index.html` renders moltbook entries with amber badge, submolt chips, author lines
5. **CI** `.github/workflows/ci.yml` stages and deploys everything to GitHub Pages
